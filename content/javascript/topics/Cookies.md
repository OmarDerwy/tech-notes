Save information about the user on the client user. They are very small in size

# 1	how it's done in JS
they are saved as key/value pairs
```js
document.cookie="name=menna; expire=<DATE FORMAT>;path="
```
to delete a cookie change the date to the past and delete the value
# 2	How to use cookies?
create an object variable and then split the key value pairs.
