# 1	intro
CV and resume are the same for fresh grads

CV type should be reverse  chronological

classic cv is number one CV
- ATS reads it better
- details are more pronounced
modern cv is trending now
- harder for ATS systems to read and some fonts cannot be read by them
infographic cvs are an option
